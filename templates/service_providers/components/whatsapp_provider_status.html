{% comment %} WhatsApp diagnostics for a Meta Cloud API messaging provider: whether the bot's message template can actually be sent, this account's numbers, and a place to try a real send. Loaded into the provider page by HTMX, so it never holds up the form. Everything here is read from the provider's `extra_data` cache. Refreshing is the only thing that talks to Meta -- it queues sync_whatsapp_provider_task, which re-fetches the numbers and re-checks the template -- and this panel polls itself until that task lands. `template_check` is a cached TemplateCheck as a dict; `template_checked` is false while nobody has checked yet, which is not the same as a check that failed. {% endcomment %}
